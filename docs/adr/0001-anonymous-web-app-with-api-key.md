# 0001. Web アプリは匿名で公開し、本文の合言葉で呼び出し元を確かめる

- ステータス: 採用
- 日付: 2026-10-18

## コンテキスト

このアプリは Claude Code のセッション（クラウドのコンテナを含む）から curl で呼ばれる。呼び出し側はブラウザを持たず、Google にログインできない。Web アプリの公開範囲を「Google アカウントを持つ全員」以上に絞ると、呼び出しはログイン画面へ転送されて届かない。

扱うのは公開範囲を設定した本人の Google ToDo リストで、読み書きの両方ができる。誰でも呼べる状態にしてはいけない。

## 決定

**公開範囲は「全員（匿名を含む）」（`ANYONE_ANONYMOUS`）にし、POST の本文に入れた合言葉がスクリプト プロパティの値と一致した呼び出しだけを受け付ける。**

- 合言葉はエディタから関数 `issueApiKey` を実行して作る（UUID 2つ分、64文字の16進）。作り直すと古いものは使えなくなる
- 合言葉は URL のクエリではなく本文に入れる。URL はプロキシやログに残りやすいため
- 合言葉が未発行のうちは、どの呼び出しも拒否する
- 受け付ける操作は ToDo リストの一覧・追加・完了・変更だけにする。削除は戻せないため受け付けない

## 結果

良い影響: 呼び出し側は URL と合言葉の2つを環境変数に置くだけで使える。OAuth の同意画面やトークンの更新が要らない。

悪い影響: 合言葉が漏れると、誰でも ToDo リストを読み書きできる。漏れたら `issueApiKey` で作り直し、呼び出し側の環境変数を替える。Web アプリの URL 自体は秘密ではない前提で扱う。

## 検討した代替案

- **Google Cloud の OAuth クライアントで Tasks API を直接呼ぶ**: このアプリが要らなくなる。ただしリフレッシュトークンを失効させないには同意画面を本番にする必要があり、本番の外部アプリにはホームページとプライバシーポリシーが必須になる。テストのままではトークンが7日で失効する（brain の `projects/brain/adr/0014-life-tasks-in-google-tasks.md`）
- **公開範囲を「Google アカウントを持つ全員」にする**: 呼び出しにログインが要り、curl から呼べない
- **合言葉をクエリ文字列で渡す**: doGet で済み実装は簡単だが、URL ごとログに残る
